입덕볶이 — 7차 패치 (교육용 웹 프로토타입)
실행: VS Code Live Server 또는 python -m http.server 8000 후 index.html 접속. GitHub Pages에는 폴더 내부 파일을 배포하세요.
기능: 메뉴 탐색, 맵기 및 옵션, 장바구니, 회원가입 및 자동 로그인, 회원별 주소·쿠폰·주문 내역, 모의 결제, 재주문, 커뮤니티 게시글·댓글 작성 및 관리.
비밀번호 최소 길이 제한은 없습니다. 입력 여부와 확인 일치를 검사합니다. 기존 계정은 유지됩니다.
테스트 계정은 가상 주소가 없을 경우 자동 등록됩니다. 재주문은 기존 장바구니에 메뉴와 옵션을 추가하며 현재 가격을 적용합니다.
보안 한계: 서버가 없는 정적 시연용 사이트입니다. 비밀번호를 포함한 회원 정보는 브라우저 localStorage에 평문 저장됩니다. 실제 개인정보 및 실제 비밀번호를 입력하지 마세요. 실제 인증, 결제, 배달, 다중 사용자 동기화는 제공하지 않습니다.
기존 ipdeok4 저장 키 유지. 메뉴와 가격 및 옵션은 js/app.js 상단, 스타일은 css/style.css에서 관리합니다. 메뉴 가격, 쿠폰, 배달비, 스코빌 수치는 시연용입니다.
